Clojure · tech.ml.dataset · Apache 2.0

Ask questions of your data with one function.

Datajure gives Clojure a compact query language for tables. Filter rows, add columns, group, aggregate and run window functions with a single function, dt, and a few keywords. Every result is an ordinary dataset.

Get started Read the docs
REPL
(dt prices
    :where #dt/e (> :volume 1000)  ; busy days only
    :by    [:sym]                  ; one group per stock
    :agg   {:days      nrow        ; count the rows
            :avg-price #dt/e (mn :price)})
Result
:sym:days:avg-price

One query function

:where, :set, :agg, :by and a few more keywords cover filtering, new columns, grouping and sorting.

Time series and cross-sections

Lags, rolling windows and as-of joins down each series; ranks, z-scores, winsorizing and quantile buckets across each date. Panel data gets both.

Expressions are values

Write #dt/e (* :price :volume) once, store it in a var and reuse it across queries.

Safe with missing data

Comparisons with a missing value are false and aggregations skip it, so blank cells don’t derail a query.

Fast, not magic

Expressions compile to vectorized column operations on tech.ml.dataset. Datajure adds syntax, not a new engine.

Errors that help

A typo such as :prcie is caught before the query runs, with a suggestion: did you mean :price?
